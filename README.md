# AI Career Agent

An AI-powered career intelligence system that analyzes a candidate's resume against a target job description, identifies skill gaps, calculates job compatibility, prioritizes missing skills, and generates a personalized career improvement roadmap.

---

## 1. Project Overview

AI Career Agent is designed to help students and job seekers understand how well their current profile matches a target job role.

The system combines:

- Resume text extraction
- Generative AI
- Structured resume analysis
- Job requirement extraction
- Semantic skill matching
- Skill gap analysis
- Skill priority classification
- Weighted compatibility scoring
- AI-generated career roadmap

Instead of simply comparing keywords, the system uses semantic similarity to identify relationships between skills while applying technology-specific safeguards to reduce incorrect matches.
